Método

Como ler estes números

  • Fonte. BADEPI v12 (INPI/CGEI), microdados de marcas: 5,15 milhões de pedidos depositados de 2000 a 2025 e 19 milhões de despachos.
  • Contagem. Pelo ano de protocolo no INPI; para designações via Madri, a data de entrada na fase nacional.
  • Despachos. O BADEPI traz só o código (DESP### até 2013, IPAS### desde então), sem descrição. Os códigos decisivos (publicação, oposição, exigência, deferimento, registro, arquivamento, indeferimento, recurso, extinção, petições) foram identificados em publicações da RPI; os demais entram como "outros".
  • Situação. Mesma regra dos demais ativos (ver método). Marcas não têm prazo máximo de vigência: "vigente" = registrada sem extinção publicada.
  • Classe principal. Primeira classe de Nice do pedido; desde 2000 o INPI adota uma classe por pedido, salvo pedidos via Madri.
